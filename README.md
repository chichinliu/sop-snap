# SOP Snap 圖文手冊（Chrome 擴充功能）

把網頁操作變成圖文手冊：**擷取 → 編輯 → 匯出**。適用於 SOP 製作、教育訓練與工作交接。

> 由 [chichinliu.com](https://chichinliu.com) 製作。所有手冊與截圖只存在你的瀏覽器（IndexedDB），不上傳任何伺服器。

## 安裝（開發者模式）

1. Chrome 網址列輸入 `chrome://extensions`，開啟右上角「開發人員模式」
2. 點「載入未封裝項目」，選擇本 repo 的根目錄（含 `manifest.json` 的資料夾）
3. 把 SOP Snap 釘選到工具列；首次安裝會自動開啟編輯器與使用說明

需要 Chrome 116 以上（Edge、Brave 等 Chromium 瀏覽器亦可）。

### 快捷鍵

| 動作 | 預設 |
|---|---|
| 擷取可視畫面 | `Alt+Shift+1` |
| 手動框選擷取 | `Alt+Shift+2` |
| 全頁捲動截圖 | `Alt+Shift+3` |
| 開始／停止點擊錄製 | 未指定（可自訂） |

到 `chrome://extensions/shortcuts` 自訂。

## 設計重點

- **遮蔽不可逆地燒進匯出圖片**：原圖與標註分開儲存，編輯時隨時可復原；但匯出 HTML／PDF 時一律扁平化成單張圖片，遮蔽區塊下的原始像素不會出現在交付物中（避免「CSS 蓋一塊黑框、右鍵另存原圖就破功」的資安漏洞）。
- **截圖不可變**：重新截圖會產生新的圖片 id，版本快照只需記錄 id，發布多個版本不會重複佔用空間，也能逐張比對截圖變更。
- **寫入不互相覆蓋**：背景擷取與編輯器同時改同一份手冊時，皆以單一 IndexedDB 交易「讀取→修改→寫回」。
- **已發布手冊一經編輯自動回到草稿**，現行版仍保留在版本紀錄中供同仁查閱。

## 已知限制

- Chrome 內部頁面（`chrome://`）、Chrome 線上應用程式商店無法擷取，這是瀏覽器的安全限制。
- 全頁捲動截圖以文件捲動為準；內容放在「內層捲動容器」的 SPA 只會擷取可視範圍。超長頁面截取上限約 30,000 px。
- Chrome 限制每秒最多擷取 2 次，連續快速點擊時會排隊依序截圖。
- **團隊版的角色與審核為「本機工作流程模式」**：可以完整走完送審→核准→發布→版本比對的流程，但不是跨裝置的權限控管。真正多人協作需要後端（帳號、同步、稽核紀錄），目前以「匯出分享套件 / 匯入」完成交接。

## 檔案結構

```
sop-snap/
├── manifest.json        MV3 設定、權限、快捷鍵
├── background.js        截圖引擎（可視／框選／全頁拼接）、點擊錄製、寫入手冊
├── recorder.js          注入頁面的點擊監聽器（產生「點擊『新增訂單』」等步驟標題）
├── popup.html/.js/.css  工具列彈出視窗
├── editor.html/.js/.css 手冊編輯器、標註工具、手冊庫、審核、版本控管
└── lib/
    ├── db.js            IndexedDB 存取（含交易式 update）
    ├── model.js         方案權限、草稿／步驟／版本、差異比對、分享套件
    ├── render.js        標註繪製與匯出扁平化
    └── exporter.js      HTML 匯出、列印／PDF
```

除錯：在 `chrome://extensions` 點 service worker 開啟 DevTools，可直接呼叫 `__sopsnap.runCapture('visible' | 'region' | 'full')`。
